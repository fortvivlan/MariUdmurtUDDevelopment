# MariUdmurt

Universal Dependencies parsing for Mari and Udmurt through cross-lingual transfer.
The planned pipeline adapts [Glot500](https://huggingface.co/cis-lmu/glot500-base)
on Mari, Udmurt, Finnish, Hungarian, Erzya, Moksha, and other Uralic languages,
then fine-tunes a parser based on
[BaseUDParser](https://github.com/fortvivlan/BaseUDParser).

Conducted under **RSF Grant No. 25-18-00222**
([project website](https://fortvivlan.github.io/controlandraise/index_en.html)).
